# Contributing

Thanks for the interest. This is a small free tool, so the bar is simple.

- Bug reports: open an issue with your Windows version and what you pasted.
- Detection rules: if a look-alike check misses a copy, an issue with both IDs (public ones only) is enough.
- Design and docs: the mockup sources live in `design/` and render with Node 20 (`npm install`, `node render.mjs all`).

By contributing you agree your contribution is MIT-licensed. Don't paste other people's private data into issues.
